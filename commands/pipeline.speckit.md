# /pipeline:speckit

Resolve the exact repository and feature, then use its installed Spec Kit
commands to specify, clarify, plan and create tasks. Treat those artifacts as
the source of truth.

For implementation, use the active Gobabygo coordinator contract and Mesh Live:
one bounded writer task, test evidence, then independent Codex or Antigravity
review. Sync approved tasks through the repository GitHub ledger when enabled.

Update `tasks.md`, the review ledger and coordinator handoff after every stage.
Stop for production, secrets, destructive actions, money movement or unresolved
product decisions. Do not invoke Claude Flow/Ruflo or create another task store.
